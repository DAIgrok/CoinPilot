# CoinPilot Site
Painel web responsivo para organizar tarefas diárias da Shopee e AliExpress.

## Como usar
- Abra `index.html` no navegador ou publique a pasta em um serviço de hospedagem estática.
- Os registros ficam no armazenamento local do navegador.
- O site não coleta moedas automaticamente nem verifica o servidor das plataformas. A confirmação é manual e o aviso é emitido apenas após a confirmação do usuário.
- Links para abrir os aplicativos podem variar conforme o dispositivo e a versão instalada.

## Publicar pelo GitHub Pages
1. Envie `index.html` para a raiz do repositório.
2. No GitHub, abra Settings > Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Escolha `main` e `/ (root)`, depois Save.
5. Aguarde a publicação e abra o endereço mostrado pelo GitHub Pages.
